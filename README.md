# 🔐 Password Generator

A modern and responsive **Password Generator Web App** built using **HTML, CSS, and JavaScript**.

This application allows users to generate strong and secure passwords with customizable options like uppercase letters, lowercase letters, numbers, symbols, and password length.

---

# ✨ Features

- 🔒 Generate strong secure passwords
- 🔢 Adjustable password length slider
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔣 Include symbols
- 🔢 Include numbers
- 📋 One-click copy to clipboard
- 💪 Password strength indicator
- 📱 Fully responsive UI
- ⚡ Smooth animations & transitions
